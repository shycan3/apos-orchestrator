# APOS v0.2.1 Release Snapshot

APOS v0.2.1 is a small dashboard recovery UX polish release: it keeps the same local orchestration model, but makes the recovery prompt handoff easier to understand on the dashboard.

## v0.2 to v0.2.1

Compared with v0.2, this snapshot does not add new functionality.

The only user-visible change is a clearer recovery prompt handoff in the dashboard:

- failed item cards now include a short note that the full recovery prompt lives in the detail panel
- the detail panel copy text now makes it explicit that the full prompt can be copied there
- the recovery path is easier to discover, but the workflow itself is unchanged

## What Did Not Change

- no new features were added
- automatic retry was not introduced
- Web Controller support was not implemented
- the dashboard still stays read-only with respect to execution policy and storage

## Dashboard Recovery UX

v0.2.1 keeps the same recovery flow as v0.2, but reduces ambiguity about where to find the full prompt text.

- failed item card guidance now points users to the detail panel
- the detail panel contains the full recovery prompt text for manual copy
- the recovery prompt is still generated by the existing report and recovery prompt builders

- Full test suite: 81 passed
- Remaining warnings: none

## Release Summary

This is a small UX polish release that clarifies recovery prompt location without changing APOS behavior or automation boundaries.
