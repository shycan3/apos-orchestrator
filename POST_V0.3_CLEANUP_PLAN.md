- Candidate runtime branch: `feature/v0.4-runtime-candidate`

## Proposed Commit Strategy

- Commit runtime source changes as a single branch-local unit on `feature/v0.4-runtime-candidate`.

- Commit documentation-only updates separately when they can land as release notes, architecture notes, or usage updates without code movement.
- Keep bridge experiment commits isolated so that their scope is obvious during review and rollback.
